# todo

The user's todo list has a day file from an earlier date with three open items,
and a backlog with one item. One open item was started as a slug that has since
been archived. On the first use of a new day the skill must triage the earlier
day's open items with the user (who carries two and backlogs one) before doing
what was asked: add an item, pull the backlog item into today, attach a note to
a carried item, and review. Everything must land in the right files: today's
day file, the earlier day file's MOVED lines, backlog.md and details/.
